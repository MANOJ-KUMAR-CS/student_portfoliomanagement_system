🎓 Student Academic Portfolio Management System

A full-stack web application designed for students to manage and showcase their academic achievements, skills, and projects. 📑✨

🚀 Features

User Authentication: Secure login and signup with JWT. 🔐

Profile Management: Update personal details and academic info. 👤

Portfolio Showcase: Add and manage projects. 🛠️

Academic Tracking: Keep a record of grades and technical skills. 📚

💻 Tech Stack

Frontend: React.js ⚛️

Backend: Node.js & Express.js 🌐

Database: MongoDB (Mongoose) & MySql
